# LoadLight

Make room to breathe.

A student stress and workload management prototype built for CodeNection 2026.

## Core idea

LoadLight helps students understand how much they are carrying, explore the impact of new commitments before saying yes, and rebalance their week before it becomes too much.

## Main navigation

Home | Tasks | What-if | Balance | Me

## Tech

- Next.js / React
- TypeScript
- CSS
- localStorage prototype state

## Setup

```bash
npm install
npm run dev
```

## Important

The prototype uses shared workload logic so Home, Tasks, What-if and Balance should not hardcode separate load values.
